# QR-Code-Generator-2026
This is an app where when you paste a website link in, it generates a free QR code for you to use. (Just a tester for the qrcode imports)

One of my biggest hatreds about using apps is when they require you to pay for the "full service." This really bothers me because hypothetically I could just make it myself, but whenever I try to stay chill and use the programs others made, I always get restricted. One of the systems were making QR codes. Nowadays, with many things digitalized,
QR codes are some of the most popular ways to spread links to people. But when I found that almost all other apps that made QR codes either had limits to the count of how many I could make or couldn't make one at all without paying for premium, I decided this would be an excellent starting project.

The progress of creation:
First I went around Instagram and other social media platforms as well as other examples to this Python-made QR Code Generator, and researched how these people did it. As I like to say I've mastered python to the point where I am comfortable to do anything I want with it, I could easily find out how to display these after I got to know which
basic inputs I needed for making this program. Furthermore, I had big fun creating my first fully functioning app that remakes other app's systems but with a cost-free advantag and it was also fun when I got to design the UI and put them into my program. This was the first time I think I actually used the real date and time sensor to check the
season of the current day and portray the correct seasonal decorative UI in my program, which actually to my surprise went very smoothly without any errors. Overall, I think I learnt new things from creating this project and once again I have proven myself wrong in the quotes of "I believe I mastered Python enough" because there are still
endless categories to learn.
